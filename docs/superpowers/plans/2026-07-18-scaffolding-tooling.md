**Goal:** Stand up the SoccerScore project skeleton — Vite+React+TS app, Vitest, Playwright, formatting, and CI/CD — so later plans (game logic, UI, expanded visual tests) can build on a working, tested, deployable foundation.

**Architecture:** Scaffold the official Vite `react-ts` template at the repo root (this repo, `C:\Users\jvosters\dev\soccerscore`, already has `.git` and `docs/superpowers/specs/`), then layer in Vitest (logic tests), Playwright (visual regression), Prettier/VS Code settings matching the sibling `basketballscore` project's conventions, and two GitHub Actions workflows (PR checks, main-branch deploy to GitHub Pages).

**Tech Stack:** Vite, React 18, TypeScript, Vitest, @playwright/test, Prettier (via npx, no permanent dependency), GitHub Actions, GitHub Pages (Actions-based deploy).

## Global Constraints

- Node version floor: 20 (required by current Vite; use in local dev and in both workflows' `actions/setup-node`).
- Package manager: npm (`package-lock.json` committed).
- Formatting: Prettier with `{ "singleQuote": true, "semi": true, "tabWidth": 2, "printWidth": 100 }` (same as `basketballscore/.prettierrc`), invoked via `npx` — not a permanent dependency, matching the sibling project's philosophy.

- GitHub Pages source: "GitHub Actions" (not a branch) — deploy workflow publishes the build artifact directly.
- TDD: from the logic-layer plan onward, pure-function logic gets a failing test written before its implementation. This plan's one piece of logic (`formatClock`/`parseClock`) follows that same pattern to establish the convention early.

```ts
import { formatClock, parseClock } from './clock';

describe('formatClock', () => {
  it('formats whole minutes and seconds as M:SS', () => {
    expect(formatClock(125)).toBe('2:05');
  });

  it('pads single-digit seconds', () => {
    expect(formatClock(61)).toBe('1:01');
  });

  it('clamps negative input to 0:00', () => {
    expect(formatClock(-5)).toBe('0:00');
  });

  it('floors fractional seconds', () => {
    expect(formatClock(59.9)).toBe('0:59');
  });
});

describe('parseClock', () => {
  it('parses M:SS into total seconds', () => {
    expect(parseClock('2:05')).toBe(125);
  });

  it('returns null for malformed input', () => {
    expect(parseClock('not a clock')).toBeNull();
  });

  it('returns null when seconds are 60 or more', () => {
    expect(parseClock('1:60')).toBeNull();
  });
});
```

- [ ] **Step 6: Implement `src/logic/clock.ts`**

```ts
export function formatClock(totalSec: number): string {
  const sec = Math.max(0, Math.floor(totalSec));
  const m = Math.floor(sec / 60);
  const s = sec % 60;
  return `${m}:${String(s).padStart(2, '0')}`;
}

export function parseClock(text: string): number | null {
  const match = /^(\d+):([0-5]\d)$/.exec(text.trim());
  if (!match) return null;
  return parseInt(match[1], 10) * 60 + parseInt(match[2], 10);
}
```
